# moodGenerator

Interactive mood generator web app.

## Version

Current version: `0.1.0` (kick-off release)

## Mood presets (v1)

1. Cozy Cabin Rain
2. Misty Forest Morning
3. Alpine White Noise
4. Neon Rain Drive
5. Moonlit Shore
6. Desert Night Heat
7. Starlit Meadow

Each preset combines:
- Setting image style
- Ambient synthesized music
- On-screen actions (rain, snow, wind, fireflies)

## Run

Open [index.html](./index.html) in a browser.

No build step required.

Note: Browsers require a user gesture before audio can play. Click `Enable Sound` once to start ambient audio.
